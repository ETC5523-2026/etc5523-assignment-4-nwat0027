# Launch the GenderForce Interactive Shiny Application

Launches the built-in Shiny application included in the package for
exploring global labor force participation rates by gender and marital
status.

## Usage

``` r
run_app()
```

## Value

Launches an interactive Shiny application.

## Examples

``` r
if (FALSE) { # \dontrun{
run_app()
} # }
```
